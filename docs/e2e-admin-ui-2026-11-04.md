# 관리자 브라우저 UI E2E — DNS·HTTPS 연결부터 위반 처리까지 (2026-11-04)

**이 문서의 수치와 판단은 1회 실행의 관찰이다.** 일반화하면 안 된다. 표기: **[관찰]** 접근 로그·DB·AWS 조회에서 직접 읽은 값, **[코드 확인]** 소스를 읽고 판단한 것(실행으로 재현하지 않음),
**[미확인]** 확인하지 못한 것. 이 시험 전 단계: [빈 공간 사진 E2E](e2e-aws-first-run-2026-11-04.md), [위반 2회 확정 E2E](e2e-aws-violation-confirm-2026-11-04.md), 계획: [dns-admin-ui-plan.md](dns-admin-ui-plan.md).
시각은 UTC. 계정 ID·IP·토큰·비밀번호는 이 문서에 적지 않는다.

## 1. 범위
- 확인한 것: ALB 접근 제한(IP) → DNS A Alias 생성 → HTTPS 인증서·응답 → **사용자가 직접 한 브라우저 시험**(시험 관리자 로그인, 위반 #5 조회, 증거 이미지, 알림 읽음, 위반 처리 완료, 로그아웃) → Claude 의 읽기 전용 사후 검증.
- 하지 않은 것: Claude 의 로그인(없음), 사진 접수, 부하, 다른 회사 데이터 요청, 장애 주입.
- 역할: 브라우저 조작은 사용자, 기준선·사후 검증은 읽기 전용(백엔드 Pod 안 SELECT 만, 비밀 컬럼 미조회).

## 2. 연결 단계 [관찰]
| 단계 | 결과 |
|---|---|
| ALB 보안 그룹 80·443 | `0.0.0.0/0` → 사용자 공인 IP `/32` 하나. `alb_ingress_cidrs` 는 기본값 없는 필수 변수. network 스택 apply(2 add / 2 destroy), 재 plan `No changes` |
| DNS | `dns-record` 스택 apply: 1 add / 0 change / 0 destroy. Route 53 A Alias(→ ALB, `evaluate_target_health = true`), 생성 33 s(Terraform 은 Route 53 변경이 INSYNC 가 될 때까지 기다린다 — INSYNC 를 별도 Change ID 로 조회하지는 않았다) |
| 이름 해석 | 권한 있는 NS 와 공용 확인자 두 곳, 이 PC 의 확인자 모두 ALB 주소로 해석(음수 캐시 문제 없음) |
| 인증서 | 주체·SAN 모두 `APP_HOST`, 검증 OK, 만료 2027-05-12 |
| 응답 | `https://APP_HOST/` 200, `http://` → 301(`https://APP_HOST:443/`), `/api/v1/healthz` 200, `/api/v1/auth/me` 비로그인 401 |
| 다른 출발지 차단 | **[미확인]** 보안 그룹 규칙은 확인했지만 다른 IP 에서 실제로 막히는지는 이 PC 에서 시험하지 못했다 |

## 5. 검증하지 못한 것과 남은 위험
- **[미확인]** 다른 IP 에서의 실제 차단, 응답 본문의 회사 범위(크기로만 확인), 다른 회사 리소스를 직접 요청했을 때의 응답 코드, 브라우저 개발자 도구(쿠키 속성·CORS 콘솔)를 사용자에게서 전달받은 결과, 이메일 실제 발송(console 백엔드), 모바일 화면.
- **IP 변경**: 공인 IP 가 바뀌면 브라우저 접속이 막힌다([dns-admin-ui-plan.md 7장](dns-admin-ui-plan.md)의 복구 절차).
- **로그인 보호 부족** [코드 확인: 실패 잠금·속도 제한을 찾지 못함, 08:12 의 연속 401 에서도 잠금 없음 관찰]. 접근이 IP 로 제한된 동안은 노출이 작다. 제한을 풀기 전에 해결해야 한다.
- **이미지 토큰이 접근 로그에 남는다** [관찰]: 이미지 주소의 경로에 서명 토큰이 들어가 백엔드 로그와 ALB 접근 로그(S3)에 기록된다. 유효 시간 300 s 라 지금은 만료됐지만, 로그 열람자가 5분 안에 쓸 수 있다.
- **처리 완료의 감사 누락** (위 4절).
- 위반 #5 는 이제 `RESOLVED` 라 "미해결 위반 + 읽지 않은 알림" 시나리오를 다시 쓸 수 없다. 반복하려면 새 위반(사진 접수, 별도 승인)이 필요하다.
- 비용: 클러스터가 켜져 있는 동안 시간당 약 $0.60([cost-and-teardown-plan-2026-11-04.md](cost-and-teardown-plan-2026-11-04.md)).
